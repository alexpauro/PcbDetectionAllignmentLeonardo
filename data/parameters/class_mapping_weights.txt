# FILE DI TRACCIAMENTO ASSOCIAZIONI CLASSI COMPONENTI PCB
# =========================================================================
# Questo file tiene traccia in modo persistente della mappatura tra le classi
# dei diversi modelli/pesi di object detection e le 13 classi di riferimento
# del modello ParsaVictor.
#
# Formato di ogni riga:
#   [modello:]<classe_originale> = <classe_parsa_victor>
#
# Se non viene specificato il prefisso "modello:", l'associazione si applica
# a tutti i modelli (regola globale).
# Se una classe originale non e' presente qui, il sistema esegue una ricerca
# basata su parole chiave e somiglianza; se incerta, chiedera' all'utente.
#
# Le 13 Classi Standard di ParsaVictor sono:
#  1) Resistor
#  2) Capacitor
#  3) Electrolytic Capacitor
#  4) IC
#  5) Inductor
#  6) Diode
#  7) LED
#  8) Transistor
#  9) Oscillator
# 10) Connector
# 11) Switch/Button
# 12) Other
# 13) Marker
# =========================================================================
